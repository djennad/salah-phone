# Salah Phone — متجر قطع غيار الهواتف

موقع إلكتروني لمحل **Salah Phone** لتصليح الهواتف وبيع قطع الغيار (على طريقة dzfast.com).

## المميزات
- **البحث باسم الهاتف** (مثلا `Redmi 9A` أو `redmi9a`) مع اقتراحات فورية، ثم صفحة الهاتف تعرض كل القطع المتوفرة له (شاشة، بطارية، موصل شحن...).
- **حسابان**: زبون عادي أو **مصلح (ريباراتور)**. المصلح يحصل على **سعر مخفض** بعد موافقة صاحب المحل من لوحة الإدارة
  (سعر خاص لكل منتج، أو نسبة تخفيض تلقائية).
- **السلة والطلب**: المسجلون فقط يطلبون، مع معلومات التوصيل (58 ولاية، البلدية، العنوان، للمنزل أو Stop desk) وحساب سعر التوصيل تلقائيًا. الدفع عند الاستلام.
- **"قطعة غير موجودة؟"**: الزبون يطلب قطعة غير متوفرة ويصل الطلب للمحل.
- واجهة **عربية / فرنسية**، مناسبة للهاتف، وزر واتساب.
- **لوحة الإدارة** `/admin`: الطلبيات وتغيير حالتها، المنتجات والمخزون والصور، الماركات والموديلات، الأقسام، الموافقة على المصلحين، أسعار التوصيل لكل ولاية، معلومات المحل.

## التشغيل
يتطلب Node.js 22.5 أو أحدث (قاعدة البيانات SQLite مدمجة، لا حاجة لخادم قاعدة بيانات).

```bash
npm install
npm start          # http://localhost:3000   —   الإدارة: http://localhost:3000/admin
npm test
```

حساب الإدارة الافتراضي: `admin@salahphone.dz` / `admin123` — **غيّر كلمة المرور فورًا** من الإعدادات،
أو حدده قبل أول تشغيل بـ `ADMIN_EMAIL` و `ADMIN_PASSWORD`.

## الإعدادات (متغيرات البيئة)
| المتغير | الوظيفة | الافتراضي |
|---|---|---|
| `PORT` | المنفذ | `3000` |
| `DB_FILE` | ملف قاعدة البيانات | `data/salah-phone.db` |
| `UPLOAD_DIR` | مجلد صور المنتجات | `uploads/` |
| `ADMIN_EMAIL` / `ADMIN_PASSWORD` | حساب الإدارة الأول | انظر أعلاه |
| `SEED_DEMO` | `0` لعدم إضافة منتجات تجريبية | `1` |
| `SECURE_COOKIE` | `1` عند استعمال HTTPS | — |
| `TRUST_PROXY` | `1` خلف Nginx/Proxy | — |
| `NODE_ENV` | `production` لتفعيل التخزين المؤقت (cache) | — |

المنتجات التجريبية تُضاف عند أول تشغيل فقط. لحذفها والبدء من جديد: `npm run reset-db`.

## البنية
```
server.js          تشغيل الخادم
lib/app.js         الـ API (Express): البحث، الحسابات، الطلبيات، الإدارة
lib/db.js          قاعدة البيانات SQLite والبيانات الأولية
lib/wilayas.js     الولايات وأسعار التوصيل الافتراضية
public/            الواجهة (index.html + js/app.js) ولوحة الإدارة (admin.html + js/admin.js)
test/              الاختبارات
```

## الأمان
كلمات المرور مشفرة (scrypt)، الجلسات بـ cookie HttpOnly، الأسعار تُحسب دائمًا في الخادم، حماية من طلبات المواقع الأخرى (CSRF)، وتحديد عدد محاولات تسجيل الدخول.
